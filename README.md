## Project Details

**Tech Stack:** MongoDB Atlas, HTML, CSS, JavaScript, AES, RSA, Node.js, Nodemailer

**Role & Contributions:** Developed secure file upload, encryption, cloud storage, access control, and decryption functionalities. Implemented AES for file encryption and RSA for secure AES key protection and sharing. Integrated Nodemailer for secure email-based communication and access management.


**Complexity:** Intermediate

**Tools/Platforms Used:** VS Code, MongoDB Atlas, Node.js, Git, GitHub

**Key Outcome:** Developed a secure cloud-based file storage system using hybrid encryption, combining AES for efficient file encryption and RSA for secure encryption-key protection and sharing, while providing controlled access to authorized users.
